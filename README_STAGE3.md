# Stage 3 — CQA Web Application

**Статус: COMPLETE.** Проверки: 249 backend + 65 frontend + 16 e2e; подробности в отчёте ниже.

Stage 3 предоставляет рабочий браузерный интерфейс поверх API Stage 1/2. Статус Stage 2 остаётся **PARTIAL**: после NVIDIA Xid 79 ещё не завершена серия настоящих inference-проверок RU/KZ/EN, длинного разговора и звонка. UI не требует доступной GPU; очереди сохраняются, исторические оценки доступны, успешные результаты не имитируются.

## Запуск с существующими данными

Первый терминал:

```bash
cd /home/wrld/Documents/freedom_case/backend
uv sync --locked --python 3.12
uv run alembic upgrade head
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000 --no-access-log
```

Второй терминал:

```bash
cd /home/wrld/Documents/freedom_case/frontend
npm ci
npm run dev
```

Открыть http://localhost:5173. Перед запуском убедитесь, что соответствующий порт не занят уже работающим сервером. Существующий `backend/.env` не заменять. Frontend использует `VITE_API_BASE_URL`, по умолчанию `http://localhost:8000/api`. `HashRouter` и `base: './'` сохранены. Worker автоматически не запускается.

## Разделы

- **Обзор**: реальные KPI, языки/каналы, распределение баллов, очередь, последние оценки и апелляции. Методика — `final_score` последней завершённой оценки каждого разговора; null исключён, число исключений показано. Ошибка AI не является нулевой оценкой.
- **Диалоги**: глобальные фильтры, поиск, пагинация, выбор нескольких/всех найденных, постановка отдельного задания или пакета, ссылки на оценки и задания.
- **Детали**: исходные роли, порядок и timestamps, копирование реплик, переключение оценок, initial/final, критерии, N/A, флаг нарушения, review warnings, точные ссылки evidence с подсветкой цитат и диапазонов.
- **Звонки**: native audio, `preload=none`, безопасная ссылка на оригинал, обработка ошибок. Оценка касается транскрипта; сопоставление ISO timestamps с перемоткой аудио не выдумывается.
- **Чек-листы**: создание, все версии, копирование, редактирование критериев/секций/шкал/описаний ступеней/N/A/весов/порядка, сохранение и активация. Нет изменения сохранённых snapshots. Веса проверяются Decimal; версия с суммой не 100 сохраняется только как неактивная.
- **Апелляции**: подача по `criterion_result_id`, просмотр контекста, решение с обязательной причиной, допустимые ответы закреплённой версии, история и серверный пересчёт.
- **AI задания**: статусы, попытки, безопасная диагностика, retry/cancel, пакеты и progress. 100% progress включает failed/cancelled и не означает 100% успешных оценок.
- **Импорт данных**: `group_id` и JSON multipart, настоящий отчёт inserted/skipped/warnings, выбор импортированного набора и batch. Подписанный URL не передаётся frontend.

## Безопасная демонстрация без GPU

В двух отдельных терминалах:

```bash
cd /home/wrld/Documents/freedom_case/backend
uv run python -m devtools.ui_server --port 8011
```

```bash
cd /home/wrld/Documents/freedom_case/frontend
npm run dev:demo
```

Открыть http://127.0.0.1:4173. Жёлтая полоса обозначает тестовую среду. Сервер создаёт **новую временную SQLite** и применяет все миграции. Рабочая база не открывается и не копируется. После остановки временные данные удаляются. Новый запуск начинает чистый сценарий.

В ней 65 синтетических диалогов, в том числе 115 реплик в первом и пять звонков; две ручные оценки `source=test`, одна queued-задача и два пакета с явно синтетической ошибкой и отменой для демонстрации retry. AI evaluations отсутствуют, worker выключен, provider направлен на закрытый loopback-порт. Никакой Qwen inference не имитируется. Тестовая разметка проверяет UI/арифметику и не является benchmark качества модели.

Локальный mock организаторов возвращает два синтетических диалога для введённого `group_id`; `FAIL-UI` демонстрирует ошибку API. Действия интерфейса используют реальные FastAPI endpoints и SQLite, а не клиентские подмены.

## Проверки

```bash
cd /home/wrld/Documents/freedom_case/backend
uv run pytest
uv run ruff check .
uv run alembic check

cd ../frontend
npm ci
npm run lint
npm run build
npm run test
npx playwright install chromium
npm run test:e2e
```

Для `test:e2e` порты 8011/4173 должны быть свободны: Playwright сам запускает изолированный backend и Vite, после завершения останавливает их. Worker, Ollama и GPU не запускаются. На CachyOS Playwright использует совместимую сборку Chromium для Linux; запуск проверен с отключённым GPU-рендерингом браузера. Отчёты/скриншоты содержат только синтетические данные и исключены из Git.
